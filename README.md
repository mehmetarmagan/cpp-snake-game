# C++ Win32 Snake Game

Bu proje, C++ ve Win32 API kullanılarak geliştirilmiş klasik bir Yılan (Snake) oyunudur.

## 🚀 Özellikler
- **Grafik & Render:** Win32 GDI ve ekran kırılmalarını önleyen Double Buffering mimarisi.
- **Skor Sistemi:** Yüksek skorların dosya sisteminde kaydedilmesi (File I/O).
- **Oyun Dinamikleri:** Farklı meyve türleri ve dinamik skor takibi.

## 🛠️ Teknolojiler
- C++
- Win32 API / GDI
